
## 🌟 项目简介

这是一个基于 **Java + SpringBoot + Vue + MySQL** 构建的完整个性化音乐推荐系统，功能持续优化中...

### 🧩 功能模块一览

- 用户登录注册（管理员·用户双角色）
- 个性化音乐推荐（基于用户协同过滤算法，按用户收藏行为构建评分矩阵并计算余弦相似度）
- 音乐信息管理（音乐类型·标签·歌曲封面·语言类别·上架时间·歌名·音乐文件·歌手·作词·作曲·收藏量分析·点击量分析）
- 音乐类型管理
- 标签管理
- 音乐评分管理（歌名·音乐类型·歌手·评分·评分日期·用户账号）
- 我的歌单管理（歌名·音乐类型·歌手·添加日期·用户账号）
- 音乐资讯管理（标题·简介·图片·内容）
- 用户管理（用户账号·用户姓名·头像·性别·手机号码）
- 我的收藏（收藏·点赞·踩·关注）
- 音乐信息评论（用户评论·管理员回复）
- 轮播图管理
- 修改密码

## ⚙️ 运行环境与工具要求

为了确保项目顺利运行，请确认您的开发环境满足以下条件：

### ✅ 推荐配置

- **MySQL**: 8.0.41
